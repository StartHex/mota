# 深潜五十 · DIVE 50

> 氧气不多了。

一个竖屏、单局、资源规划向的迷宫爬塔游戏。玩法内核承接《魔塔》那套「血量就是时间、每一步都是取舍」的设计，换成深海钻井平台的世界观：**氧气就是你的血**，你从第 1 层舱段一路下潜到第 50 层。

50 层打完一局约 40–60 分钟，适合手机竖屏碎片时间，商业化走激励视频（IAA）。

## 设计上的三条铁律

1. **广告只兑换时间、信息、容错，绝不兑换资源和数值。**
   广告能让你复活、能回到旧楼层、能提前看一条情报；但不能给你加攻击力、不能给你钥匙。魔塔的最优解是唯一的，任何资源注入都会让关卡设计失效。

2. **全图 11×11 可见，不做镜头跟随。**
   这个玩法爽在「站在这里就能把整层算清楚」。镜头一跟，规划感直接崩掉。

3. **每一层自动存档，允许回溯。**
   原版魔塔的「一命到底」在手机上会劝退 90% 的人。改成每层存档后，重来成本变成 3 分钟而不是 40 分钟 —— 而广告正好可以挂在「重来成本」上。

## 素材工具

```bash
python3 tools/prep_sprite.py raw/anglerfish.png -o prototype/assets/sprites/mon-anglerfish.png
python3 tools/prep_sprite.py icon/*.png -o /tmp/out --erase-corner --size 64
```

做四件事：擦掉右下角水印 → 抠掉品红底 → 裁到内容边界 → 缩放到目标尺寸。

| 参数 | 默认 | 说明 |
|---|---|---|
| `--erase-corner` | 关 | 清掉右下角水印区（0.80/0.88 起算） |
| `--key` | magenta | 抠图底色：`magenta` / `green` / `blue` |
| `--crop` | 0 | 四周各裁掉多少比例（切水印的备用手段） |
| `--size` | 32 | 输出边长 |
| `--tol` / `--soft` | 60 / 40 | 抠图容差与软边 |

精灵放进 `prototype/assets/sprites/`，文件名对上就自动替换内置矢量图标，不用改代码。
