# 精灵素材放置目录

把 PNG 放进这里，**文件名对上就自动替换内置矢量图标**，不用改代码。
没有对应文件的，自动回退到内置图标。

| 文件名 | 用途 | 尺寸 |
|---|---|---|
| `hero.png` | 主角潜水员 | 32×32 |
| `mon-anglerfish.png` | 灯笼鱼 | 32×32 |
| `mon-shrimp.png` | 盲虾群 | 32×32 |
| `mon-octopus.png` | 巨型章鱼 | 32×32 |
| `mon-arm.png` | 失控机械臂 | 32×32 |
| `item-keycard-yellow.png` | 黄卡 | 32×32 |
| `item-keycard-blue.png` | 蓝卡（预留） | 32×32 |
| `item-oxygen.png` | 备用气瓶 | 32×32 |
| `item-cutter.png` | 切割器核心 | 32×32 |
| `item-armor.png` | 抗压层 | 32×32 |
| `item-scrap.png` | 零件箱 | 32×32 |
| `door-yellow.png` | 黄门 | 32×32 |
| `door-blue.png` | 蓝门 | 32×32 |
| `stairs.png` | 下行梯 | 32×32 |

要求：透明背景、最近邻缩放、1px 深色描边、硬边无抗锯齿。
提示词见 `docs/美术素材生产提示词包.md`。
